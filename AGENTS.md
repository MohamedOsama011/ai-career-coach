# AICareerCoach

## Product Vision
An AI-powered career coach that helps job seekers analyze their CV, find matching jobs, generate personalized learning roadmaps, and prepare for interviews — all tailored to the user's profile and target role.

## Tech Stack
- **Frontend:** Angular 21 (standalone components, signals, `@for`/`@if` control flow)
- **Backend:** .NET 8 Web API, EF Core, SQL Server
- **AI:** GitHub Models (`gpt-4o-mini`, `text-embedding-3-small`)

## Project Structure
- `frontend/` — Angular app
- `backend/` — .NET solution (DAL, BLL, API)
- Build frontend: `npx ng build` (from `frontend/`)
- Build backend: `dotnet build` (from `backend/`)

## Core Entities
- `User` — application user (Identity)
- `CV` — uploaded CV with extracted text and embedding
- `Job` — job listing with required skills
- `Roadmap` — admin-curated template with ordered steps
- `RoadmapTemplateEmbedding` — embedding vectors per template (for similarity matching)
- `UserRoadmap` — personalized roadmap per user (steps + gapAnalysis JSON, cached by cvHash+targetRole)
- `AiFeedbackCache` — cached CV feedback results
- `InterviewSession` / `InterviewMessage` / `InterviewScorecard` — mock interview: session config + transcript + lazy-evaluated report

## Architecture Decisions
- Skills page layout: **CSS Grid `1fr 1fr`**, horizontal rows with stacked bars (dark = current, blue = target)
- Level-to-percent mapping: `None=0, Beginner=25, Intermediate=50, Advanced=75, Expert=100`
- CV trimmed to **12000 chars** (`CvConstants.MaxLength`) in all services — unified via `CvConstants.cs`
- Roadmap generation pipeline: **two-pass gap-driven** — Controller → `UserRoadmapService` → `RoadmapTemplateStore` (similarity) → `RoadmapLlmService` Pass 1 (assess seniority + identify gaps) → Pass 2 (build gap-driven steps, priority-ordered). Template = tech-stack reference only, NOT a rigid skeleton.
- Change detection: use `ChangeDetectorRef.detectChanges()` after async data fetch in components
- ForceRegenerate flag on `GenerateRoadmapRequestDto` bypasses cache
- Interview question-gen: plain chat (no JSON), temp 0.5, 2-retry + 30s CT + fallback question
- Interview scorecard: JSON mode (`CreateJsonObjectFormat`), temp 0.2, validation (score range, grade/rating enum, question count), 2 retries then throw
- Interview 3 entities in one file (`InterviewSession.cs`): Session, Message, Scorecard
- Interview session stores `SummaryContextJson` (4000-char CV excerpt snapshot) at start time
- `HasMaxLength(-1)` over `int.MaxValue` for `nvarchar(max)` columns
- `HasOne(s => s.User)` over `HasOne<User>()` avoids shadow FK `UserId1`

## Coding Conventions
- Angular: standalone components, no NgModules
- Angular: `signal()` over `BehaviorSubject` for component state
- Backend: interfaces in `Interfaces/`, implementations in `Services/`
- Backend: DTOs in `DTOs/` matching API contract
- No `any` types in new code
- CSS: utility-first approach, no Tailwind
